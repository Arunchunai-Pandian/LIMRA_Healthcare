# LIMRA Healthcare Website

Official website for LIMRA Healthcare — Connecting Indian healthcare leadership, clinical expertise, and strategic opportunities with Philippine healthcare institutions.

## Structure
- `index.html` — Homepage with interactive hero video panel & strategic pillars
- `about.html` — About LIMRA, leadership, cross-border bridge, and strategic vision
- `platform.html` — Cross-border healthcare advisory & partnership platform
- `network.html` — Clinical and institutional hospital network
- `contact.html` — Global inquiries & contact form (Web3Forms integrated)
- `styles.css` — Tailwind CSS & custom brand styling
- `script.js` — Navigation, smooth scrolling & form interaction
- `assets/` — Production-optimized media, video loops, and SVG branding

## Deployment
This repository is static-ready. It can be deployed directly to **GitHub Pages**, **Vercel**, **Netlify**, or any static web host with zero build step required.
